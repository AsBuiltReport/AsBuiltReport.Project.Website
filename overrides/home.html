Document your datacenter with PowerShell.

AsBuiltReport is an open source PowerShell framework that documents your infrastructure for you, for any platform with a PowerShell module or REST API. Choose your vendors, level of detail, health checks, styling and language, then get the report in Word, HTML or text, by email if you like.

Generate your first report Browse report modules

Runs on Windows PowerShell 5.1 and PowerShell 7. MIT licensed.

PowerShell 7 
PS> New-AsBuiltReport -Report Microsoft.Azure `
      -Target $TenantId `
      -UseInteractiveAuth `
      -Format Word,HTML `
      -OutputFolderPath ~/Reports `
      -EnableHealthCheck

Microsoft Azure As Built Report has been saved to '~/Reports'.
